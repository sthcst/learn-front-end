# React Hello World App

A minimal React app built with Vite that displays "Hello World". A simple starter project for learning React fundamentals.

## 🚀 Quick Start

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Run the Development Server
```bash
npm run dev
```

### Step 3: Open in Browser
Go to `http://localhost:5173/` and you'll see "Hello World"!

---

## 📁 Project Structure

```
learn-front-end/
├── index.html           # Entry HTML file

│
└── src/

    ├── App.jsx          # Main component
    └── index.css        # Styling
```
